# v1.3.5: Thinking view (PR pending)

**Status**: NOT RUN
**Needs**: an AI provider that streams reasoning (a thinking model) with AI Assistant switched on
**Time**: 20 minutes

The automated tests cover the colours and the scroll rules. These checks look
at the real boxes and the mouse wheel.

## Colours

1. **Each mode has its own colour**
   Do: With a reply that has a Thinking row, click the row to cycle through collapsed, compact, extended and open. Do this on each of the four themes.
   Expect: The four modes show four clearly different colours. On the two dark themes the text is pastel. On the two light themes it is dark text on a pastel pill. The pill does not shift or resize anything.
   If it fails: Note the theme, the mode and a screenshot.

## Scrolling while it streams

2. **Extended box holds its place**
   Do: Ask a question that makes the model reason for a while. Set the box to extended. While it streams, scroll the wheel up over the box. Wait for more text to arrive. Then wheel back to the bottom.
   Expect: With the wheel up, the text holds its place as more arrives. At the bottom it follows the new text again.
   If it fails: Note whether it jumped or stopped following.
   Result:

3. **Compact box holds its place**
   Do: Repeat check 2 with the box in compact mode.
   Expect: The same result as check 2.
   If it fails: Note what differs.

## Scrolling the chat

4. **A finished box does not take the wheel**
   Do: On a finished reply set the Thinking box to compact, then extended. Put the pointer over the box and scroll the wheel.
   Expect: The chat scrolls. The box never does.
   If it fails: Note the mode and whether the box moved.
   Result:

5. **No catching on a box**
   Do: With several Thinking boxes in the chat, scroll up through the history with the wheel so that the pointer passes over them.
   Expect: The scroll never catches or stops on a box.
   If it fails: Note which mode the box was in.

6. **Opening keeps your place**
   Do: Scroll an extended box part way down its text. Click the row once to go to open.
   Expect: The text you were reading stays in view.
   If it fails: Screenshot before and after.
