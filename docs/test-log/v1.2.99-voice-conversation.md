# v1.2.99: voice conversation mode with Windows speech (PR #117)

**Status**: NOT RUN
**Needs**: laptop speakers and a headset (wired or Bluetooth); a microphone; an AI key; an SSH host; the English (UK) Windows voice pack if you can add it (Windows Settings > Time & language > Speech); a Mistral key for the AI speech rows of the first group; a second microphone if you have one
**Time**: 75 minutes

Conversation mode keeps the microphone open. A pause ends your turn and sends
it, and the reply is read aloud. Start it in Settings > Voice: Enable voice
on, Mode set to Conversation, Speech set to Windows speech, Save. Press Right
Shift in the AI panel to start a conversation, and press it again to end it.

## Does the app hear itself?

Run these first. If the app's own voice starts its own listening and stops the
conversation, the rest is hard to judge. For each, ask a question that gets a
long answer, such as "Explain in about ten sentences how tides work".

1. **Laptop speakers, normal volume, Windows speech**
   Do: Use the laptop speakers (no headset). Set the volume to a normal level for a quiet room. Speech set to Windows speech. Start a conversation and ask the question. Say nothing while the reply plays.
   Expect: The whole reply is read to the end. The header never shows "Hearing you..." from the app's own voice and the conversation does not stop itself. After the reply it goes back to "Listening...".
   If it fails: Note: which voice, speakers or headphones, the volume level, and how far into the reply (which sentence) it stopped. Also the header text when it stopped, and whether it said "Ignored the assistant's own voice".

   Do: Same as check 1 with the volume near maximum.
   Expect: The same: the reply is read to the end and nothing stops it.
   If it fails: Note the same four things.

## A full conversation

8. **Start, speak, hear the reply**
   Do: Press Right Shift in the AI panel with a connected session. Say "Hello, who are you?". Pause.
   Expect: The header goes Listening, Hearing you, Sending, Working, Speaking, then Listening. The reply is spoken. Only prose is read: no code, tables or commands.
   If it fails: Note the header text where it stuck.
   Result:

9. **Voice choice and the English (UK) pack**
   Do: Open Settings > Voice and look at the Windows voice list. Do this on a PC with the UK pack and, if you can, without.
   Expect: With the pack, Automatic picks an English (UK) woman's voice, shown as "Automatic (<name>)". Without it a note says "No British English woman's voice is installed: add English (United Kingdom) under Windows Settings > Time & language > Speech". Choose a named voice and Save: that voice speaks.
   If it fails: Screenshot. Note which voices are listed.
   Result:

10. **Play sample**
    Do: Settings > Voice, press "Play sample".
    Expect: A short sample is spoken in the chosen voice. Tick Enable voice and set Mode to Conversation but do not Save: Play sample then does nothing (the notes say so).
    If it fails: Note what you heard.
    Result:

11. **A command with an approval card**
    Do: In a conversation say "Check the free space on this machine". When the card appears, do not speak.
    Expect: The assistant announces "I need your approval to run a command." The microphone indicator is off while the card waits. Click Run by hand. The result is spoken after.
    If it fails: Note what was announced and whether the mic light stayed on.
    Result:

12. **After many voice turns**
    Do: Run several turns in a row until the automatic round cap is reached.
    Expect: The next step needs an on-screen approval. It is not approved by voice.
