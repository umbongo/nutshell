# v1.2.89: themed checkboxes (PR #104)

**Status**: NOT RUN
**Needs**: all four themes (pick each in turn in Settings); the ability to change the Windows display scale; ideally a second monitor at a different scale
**Time**: 15 minutes

The checkboxes were seen only under Wine at 96 DPI. The password prompt is the
box that asks for an SSH key passphrase or a password.

## Looks

1. **Settings checkboxes on the four themes**
   Do: Open Edit > Settings. Visit every page that has a checkbox (for example General, Debugging, AI Assistant > Provider, Voice). Look at one ticked and one unticked box on each page. Repeat on each of the four themes.
   Expect: A rounded box about the size of the text line. Unticked has a visible outline. Ticked is filled with the accent colour with a white check mark. The label text is readable on every theme.
   If it fails: Screenshot. Note the theme, the page and the box.
   Result:

2. **The Debugging page label is not cut off**
   Do: Open Settings > Debugging. Read the row "Keep recent detail for issue marks, at".
   Expect: The whole label is visible, with no "..." at the end.
   If it fails: Screenshot.
   Result:

3. **No flash of the old box**
   Do: Click a checkbox on and off several times. Press Space on a focused one. Tab to another box and back.
   Expect: No frame of a small old-style square appears at any moment. The box changes cleanly.
   If it fails: Say which action flashed.
   Result:

4. **Focus ring on a ticked box**
   Do: Tick a box, then Tab away and back to it with the keyboard.
   Expect: A visible focus ring goes around both the box and its label, and can be seen on a ticked box too.
   If it fails: Screenshot.
   Result:

5. **Password prompt checkbox**
   Do: Connect to an SSH profile that asks for a password or key passphrase and has no saved one, so the prompt appears.
   Expect: The checkbox in the prompt looks the same as those in Settings, with a readable label.
   If it fails: Screenshot.
   Result:

## Scaling

6. **125 % and 200 %**
   Do: Set the Windows display scale to 125 %, then 200 %. Open Settings and the password prompt each time.
   Expect: The boxes grow with the text. The check mark stays crisp. No label is cut off.
   If it fails: Screenshot at that scale.
   Result:

7. **Dragged to a monitor with a different scale**
   Do: With two monitors at different scales, open Settings on the first, drag it to the second.
   Expect: The boxes resize to match the new scale and stay clear.
   If it fails: Screenshot. Note both scales. Skip if there is no second monitor and write "skipped, one monitor".
