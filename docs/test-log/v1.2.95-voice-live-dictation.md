# v1.2.95: live dictation (PR #112)

**Status**: NOT RUN
**Needs**: a microphone; an OpenAI key (the maintainer's provider) and a Mistral key if you have one; a Wi-Fi switch or a way to cut the network for a minute; an SSH host; a Linux host with `vi` and `less` for check 8
**Time**: 45 minutes

With OpenAI or Mistral as the speech-to-text provider, the words stream into the
AI panel's input box while you speak. Set it up in Settings > Voice: Enable
voice on, Provider OpenAI (or Mistral), your key, Save. Key mode Toggle
(Right Shift starts and stops). Nothing is sent until you press Send.

## Live text

1. **OpenAI live words**
   Do: Provider OpenAI, Live model `gpt-live-transcribe`, Language English (UK). Press Right Shift, say "I would like to organise the colour scheme", pause, say another sentence, press Right Shift.
   Expect: Words appear in the box while you speak. A provisional word may change when its segment finishes. The text ends up correct, with "organise" and "colour" spelt the British way. The words are not garbled (the 24 kHz audio is right).
   If it fails: Note what appeared against what you said.
   Result:

2. **Mistral live words**
   Do: Provider Mistral, Live model `voxtral-mini-transcribe-realtime-3`. Repeat check 1.
   Expect: Words appear while you speak and the final text is right. Skip if you have no key.
   If it fails: Note any message in the chat.
   Result:

3. **Words go after a draft**
   Do: Type "note:" in the box. Record a sentence.
   Expect: The words follow "note:" after one space. Nothing is sent.
   If it fails: Screenshot.

## The box while recording

4. **Typing is paused**
   Do: While recording, try typing letters, pasting, cutting, Backspace, Delete and undo.
   Expect: None of them change the box. Ctrl+C still copies. Clicking in the box does not move where the new words go. This stays so until the last words arrive.
   If it fails: Note which key changed the text.
   Result:

5. **Send or Enter while recording**
   Do: While speaking, press Send (or Enter).
   Expect: The microphone stops, "Transcribing..." shows, the final words arrive, then the message is sent. If the last words are slow it says "The last words did not arrive. Check the text and press Send." and sends nothing.
   If it fails: Note the order of events and any message.
   Result:

6. **Escape in the panel**
   Do: Type "keep me", then record, then press Escape with the AI panel focused.
   Expect: The recording's words disappear. "keep me" stays.
   If it fails: Note what was removed.
   Result:

7. **Escape in the terminal**
   Do: Start a recording. Click the terminal. Run `less /etc/passwd` on the Linux host and press Escape inside it.
   Expect: Escape goes to the terminal (less sees it). The recording carries on.
   If it fails: Note whether the recording stopped.
   Result:

8. **Shift+Insert while recording**

   Expect: Text is not pasted. (The notes call this an accepted risk: it may be caught as "box changed". Note what you see.)

## Connection problems

12. **Wi-Fi off mid-recording**
    Do: Start recording and speak. Switch Wi-Fi off. Keep speaking, then stop the recording. Switch Wi-Fi on first if needed so the fallback can upload.
    Expect: A note "Live text stopped: the rest will appear when you stop". When you stop, one transcription of the whole recording replaces the live text.
    If it fails: Note the messages.
    Result:

13. **Fallback also fails**
    Do: Repeat check 12 but leave Wi-Fi off when you stop.
    Expect: The live text stays, with a note in the chat.
    If it fails: Note the message.
    Result:

14. **Wrong key or wrong model**
    Do: Put a wrong key in Settings > Voice, Save, record. Then put the right key and a wrong Mistral model (live model name that does not exist), record.
