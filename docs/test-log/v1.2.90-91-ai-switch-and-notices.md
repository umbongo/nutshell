# v1.2.90-91: AI assistant switch and notice dialogs (PRs #106, #107)

**Status**: NOT RUN
**Needs**: a copy of the real `nutshell.config` that has an AI key saved (work on a copy, in a scratch folder); an SSH host; an AI key; Narrator (Win+Ctrl+Enter) for check 7; a taskbar that can be moved to the top or left edge for check 21
**Time**: 40 minutes

The AI assistant has an Enable switch. While it is off, Nutshell must load
none of the assistant. These checks use a scratch copy of the exe and config
so the real config is safe.

## Upgrade and first run

1. **Upgrading a config that already has a key**
   Do: Copy `nutshell.exe` and a copy of the real `nutshell.config` into an empty folder. Run `.\nutshell.exe` from there.
   Expect: A notice opens at launch. It lists the settings that were added and the value each was given, in plain words. "Enable AI assistant" is on, because a key was already saved. Close it. Open the AI panel (button in the tab strip or Ctrl+Shift+Space): it works.
   If it fails: Screenshot of the notice. Note any setting named that you did not expect.
   Result:

2. **A first run with no config**
   Do: In another empty folder with only `nutshell.exe`, run `.\nutshell.exe`.
   Expect: A notice says a new config file was written and lists each optional feature (AI assistant, voice) as off. A file `nutshell.config` now exists in the folder.
   If it fails: Screenshot. Say whether the file exists.
   Result:

3. **The notice does not come back**
   Do: Close and start it again in the same folder.
   Expect: No upgrade notice the second time.
   If it fails: Screenshot.
   Result:
