# v1.3.7: terminal reset and row length (PR pending)

**Status**: NOT RUN
**Needs**: an SSH session or the local shell with bash or zsh; the Session Manager; a light and a dark theme
**Time**: 20 minutes

The automated tests cover the parser and the reflow rule. These checks look at the real window.

## Reset and erase

1. **ESC c in the shell**
   Do: Run `clear; seq 1 50; printf '\033c'`. Then scroll back with the mouse wheel and run a command.
   Expect: The screen is blank and the cursor is at the top left. The scrollback still scrolls back to the earlier lines. The prompt works.
   If it fails: Note what stayed on screen and where the cursor was.
   Result:

2. **ESC c in a full-screen program**
   Do: Start `less` or `vim`. Run `printf '\033c'` from another tab on the same shell, or type the reset in the program if it allows. Quit and look at the screen.
   Expect: The terminal is back on the normal screen, blank, and the shell responds.
   If it fails: Note which program, and what the screen showed.
   Result:

3. **Erase then resize**
   Do: Run `printf 'abc\033[2D\033[K'`. Make the window narrower, then wider.
   Expect: No stray blank line appears.
   If it fails: Note how many blank lines appeared.
   Result:

4. **A wrapped, edited command line**
   Do: In zsh or bash with readline type a command longer than the window width. Press Home and delete a few characters. Make the window narrower and then back to its width.
   Expect: No lines merge and none vanish.
   If it fails: Note what the line looked like before and after.

## Session Manager

5. **The empty list hint**
   Do: Move or rename your sessions file aside so no sessions are saved. Open the Session Manager. Click elsewhere so the list loses focus. Add a session, then delete it again. Repeat on a light and a dark theme and at 150 % scaling.
