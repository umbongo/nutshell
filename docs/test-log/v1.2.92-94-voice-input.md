# v1.2.92-94: voice input (PRs #108, #109, #110)

**Status**: NOT RUN
**Needs**: a working microphone; a headset (a Bluetooth one if you have it); a second microphone (USB or webcam) for check 12; a European keyboard layout for check 14 if you have one; keys for OpenAI, plus Groq, Mistral and Google Gemini if you have them; an SSH host; a scratch folder with a copy of the exe and config
**Time**: 60 minutes

The maintainer tested v1.2.93 and v1.2.94 once. The notes record that review by
default works, the gain slider and meter look good, the header status works and
the Language dropdown looks good. Those four are not repeated here. Everything
else below has not been run.

Voice is off by default and needs the AI assistant. Enable both: Settings >
AI Assistant > Provider > Enable AI assistant, then Settings > Voice > Enable voice,
then Save. The default push-to-talk key is Right Shift in Toggle mode (press
once to start, press again to stop). The AI panel must have the focus.

## Getting started

1. **Upgrade notice for a voice config**
   Do: Put a copy of your v1.2.93 config (with `voice_review` in it) in a scratch folder with the new exe. Start it.
   Expect: An upgrade notice lists "Voice: send automatically: off, so your words wait in the box for you to review" and "Voice: microphone gain: 0 dB". If the language was empty it also lists "Voice: language: English (UK)". It does not list a dozen voice settings. It does not say voice was turned on.
   If it fails: Screenshot of the notice.
   Result:

2. **Settings > Voice on a fresh config**
   Do: In a folder with no config, start the exe, open Settings > Voice (tick Enable voice and the assistant first).
   Expect: Push-to-talk key shows Right Shift. Key mode shows Toggle. The "Mic start delay (ms)" field is greyed under Toggle and active under Hold to talk. The "Send automatically when I finish speaking" box is unticked, and its label is not cut off.
   If it fails: Screenshot of the page.
   Result:

3. **An old untouched 1.2.92 config**
   Do: Put a 1.2.92 config with untouched voice settings (voice off) in a scratch folder. Start the new exe.
   Expect: It opens as Right Shift and Toggle with no upgrade notice about the key. A config with voice enabled keeps Right Ctrl and Hold to talk.
   If it fails: Note which key and mode it opened with.
   Result:

## Recording basics

4. **Right Shift in Toggle mode**
   Do: Click in the AI panel input box. Press and release Right Shift. Say a short sentence. Press Right Shift again.
   Expect: The microphone button pulses and the box reads "Listening... press Right Shift again to finish". After the second press, "Transcribing...", then the words appear in the box. Nothing is sent. Focus is in the box with the caret at the end.
   If it fails: Note the status text and whether the words arrived.
   Result:

5. **Hold to talk at three delays**
   Do: In Settings > Voice set Key mode to Hold to talk and Mic start delay (ms) to 0. Save. Hold Right Shift, speak, release. Repeat with 150 and with 400.
   Expect: At each delay the words are captured. A tap shorter than 300 ms records nothing and starts no recording.
   If it fails: Note the delay at which it failed and what was missing (first word cut off?).
   Result:

6. **Words are added to a typed draft**
   Do: Type "hello" in the box. Record a short sentence.
   Expect: The words go after "hello" with one space between. Nothing is sent.
   If it fails: Screenshot.
   Result:

7. **Send automatically ticked**
   Do: Tick "Send automatically when I finish speaking" in Settings > Voice. Save. With an empty box record a sentence. Then type a draft and record again.
   Expect: With an empty box the words are sent as before (any approval card still asks). With a draft, the words are added and not sent. The cue says "to send".
   If it fails: Note what was sent.
   Result:

## Keys that must not start a recording

8. **Right Shift chords**
   Do: In the terminal and then in the AI box, type a capital letter with Right Shift. Then Shift+click, Shift+Insert (paste), Ctrl+Shift+C, Ctrl+Shift+V and Shift+arrow keys. Also Left Shift with a letter.
   Expect: None of them starts a recording. Capitals type normally.
   If it fails: Note the combination that started one.
   Result:

9. **Other modifier held first**
   Do: Hold Ctrl, then press Right Shift. Hold Windows, then press Shift and S (Win+Shift+S).
   Expect: No recording starts.
   If it fails: Note the combination.

10. **Shift with the numpad, NumLock on**
    Do: With NumLock on, press Shift with a numpad arrow key, during and outside a recording.
