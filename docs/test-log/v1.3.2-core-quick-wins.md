# v1.3.2: core quick wins (PR #122)

**Status**: NOT RUN
**Needs**: an AI provider key with the assistant enabled; a Linux host with `python3` for check 1; a Custom provider only for check 1
**Time**: 10 minutes

Only the Custom provider's models URL touches Windows code. The rest is
covered by the automated tests. They are listed here because the notes record
that none of it has run on Windows.

## Settings

1. **Custom provider models URL with no path**
   Do: On the Linux host, run `python3 -m http.server 8000` and leave it running. In Nutshell open Settings > AI Assistant > Provider. Tick Enable AI assistant. Set Provider to Custom. Set Base URL to `http://<linux host>:8000` (no path after the port). Type any text in API key. Press the refresh button next to Model. Press Cancel in Settings afterwards (no need to save).
   Expect: The Linux terminal prints a line `GET /models` for the request. It must not be a request for another host. A "Refresh Models" notice then appears saying the models could not be fetched (the test server has no model list). That is fine.
   If it fails: Note the path the Linux server printed, or the exact text of the notice. Screenshot of the notice.
