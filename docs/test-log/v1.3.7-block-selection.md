# v1.3.7: Alt+drag block selection (PR pending)

**Status**: NOT RUN
**Needs**: an SSH session or the local shell with several rows of text on screen; a light and a dark theme
**Time**: 20 minutes

The automated tests cover the rectangle maths and the copy. These checks use the real mouse, keyboard and menu bar.

## Making a block

1. **Drag a rectangle**
   Do: Print several rows of text. Hold Alt, drag a rectangle over some rows, release the mouse button, then release Alt. Paste into a text editor.
   Expect: A rectangle is highlighted and the menu bar does not open. The paste gives each row's slice on its own line.
   If it fails: Note what was highlighted and whether the menu opened.
   Result:

2. **Alt alone**
   Do: Press and release Alt without touching the mouse.
   Expect: The menu bar opens as before.
   If it fails: Note what happened.
   Result:

3. **Alt released first**
   Do: Hold Alt, drag a rectangle, release Alt first, then the mouse button.
   Expect: No menu opens.
   If it fails: Note whether the menu opened.
   Result:

4. **Dragging past the edge**
   Do: With plenty of scrollback, Alt+drag past the top edge of the terminal and then past the bottom edge.
   Expect: The terminal scrolls and the rectangle follows the pointer.
   If it fails: Note the direction and what the rectangle did.
   Result:

5. **Shift+click and plain click**
   Do: With a block selected, Shift+click outside it. Then click once without Shift.
   Expect: Shift+click keeps it a rectangle. The plain click clears it.
   If it fails: Note which shape you got.
   Result:

## Awkward cases

6. **Two quick drags**
   Do: Do two quick Alt+drags at one spot, one straight after the other.
   Expect: Both times a rectangle appears, never a word selection.
   If it fails: Note which attempt gave a word.
   Result:

7. **AltGr and Ctrl+Alt**
   Do: Press AltGr+click (or Ctrl+Alt+click) and drag. Then press and release Alt alone.
   Expect: The click starts a normal selection, not a block. Alt alone still opens the menu.
   If it fails: Note which key gave a block, or whether the menu stayed shut.
   Result:

8. **Other mouse buttons**
   Do: Hold Alt and right-click, then middle-click in the terminal. Then Alt+click on the AI panel's splitter and release.
   Expect: No menu opens on release in any of the three cases.
   If it fails: Note which one opened the menu.
   Result:

9. **Blank cells**
   Do: In a shell run `printf 'abc\r\033[5@'`. Alt+drag over the blanks and `abc`, then paste.
   Expect: The paste contains `abc`.
   If it fails: Note what the paste held.
   Result:

10. **Accented text**
   Do: Print a line with accented letters, for example `printf 'e\xcc\x81 a\xcc\x80 n\xcc\x83\n'`. Alt+drag a block over it and paste.
   Expect: No accent mark appears alone in the paste.
   If it fails: Note which letters lost or gained an accent.
