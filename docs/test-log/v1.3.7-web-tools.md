# v1.3.7: web tools (PR pending)

**Status**: NOT RUN
**Needs**: AI Assistant and its web tools switched on, a working AI provider key; for check 6 the Wine or Windows harness

The automated tests cover the query encoding, the address checks and the watchdog on a local server. These checks use the real internet.

## Search and fetch

1. **A search with awkward characters**
   Do: Ask the assistant to search the web for a phrase with spaces, an `&` and a non-English letter, for example `fish & chips café`.
   Expect: The results are sensible and match the phrase.
   If it fails: Note the phrase and what came back.
   Result:

2. **A normal fetch**
   Do: Ask the assistant to fetch a normal public page.
   Expect: It works as before.
   If it fails: Note the page and the error.
   Result:

3. **Stop during a slow fetch**
   Do: Ask for a slow page, and click Stop while it is waiting. Then close Nutshell.
   Expect: The fetch ends at once and Nutshell exits cleanly.
   If it fails: Note how long it took and whether Nutshell hung on exit.
   Result:

4. **A page that never finishes**
   Do: Ask for a page from a server that accepts the connection and then answers very slowly or never.
   Expect: After about the per-page time the assistant reports "The page did not answer in time", not "HTTP request failed".
   If it fails: Note the message and how long it took.

## Custom search address

5. **A space in the address**
   Do: In Settings > AI Assistant > Web Access choose Search Engine Custom and put a space in the Search URL. Ask the assistant to search. Then open the help for Search URL.
   Expect: The search is refused with a plain message. The help says how the search words are added.
   If it fails: Note the message and the help text.
