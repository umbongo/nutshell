# v1.3.6: AI speech follow-ups (PR pending)

**Status**: NOT RUN
**Needs**: AI Assistant and Voice switched on; a Mistral key (a wrong one for check 3); a Custom speech server you control; for check 7 the Wine or Windows harness
**Time**: 25 minutes

The automated tests cover the checks on the Base URL, the WAV reader and the fence rule. These checks need real servers and ears.

## Settings

1. **A Base URL with a query**
   Do: In Settings > Voice set Speech to AI speech and the speech provider to Custom. Set the speech Base URL to your server's address ending in `?x=1`. Click Play sample.
   Expect: A plain message says the speech Base URL is not valid.
   If it fails: Note the message, or that the sample played.
   Result:

2. **An empty port**
   Do: Set the speech Base URL to `http://localhost:/v1` with a server listening on port 80 on this PC. Look at the line under it, then click Play sample.
   Expect: The URL is accepted, the line names `localhost` and the sample plays.
   If it fails: Note the line and the message.
   Result:

3. **A wrong Mistral key**
   Do: Choose Mistral as the speech provider with a wrong key. Click Play sample.
   Expect: The note says the provider refused the key. It does not mention the Base URL.
   If it fails: Note the note's text.
   Result:

## Listening

4. **A WAV with a trailer**
   Do: Point the Custom speech server at one that sends a WAV with a small trailer after its audio. Click Play sample.
   Expect: The sample plays cleanly with no noise at the end.
   If it fails: Note what you heard at the end.
   Result:

5. **A fenced code block**
   Do: Ask the assistant for a reply that contains a fenced code block, with AI speech on.
   Expect: The code is not read aloud and the text after it is.
   If it fails: Note what was read and what was skipped.
   Result:

6. **A list item with a code span**
   Do: Ask for a reply with a list item that starts with a one-line code span in triple backticks, followed by more text.
   Expect: The rest of the reply is still read.
   If it fails: Note where the reading stopped.
