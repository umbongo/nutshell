# v1.3.5: Settings, help tips and DPI (PR pending)

**Status**: NOT RUN
**Needs**: two monitors with different scaling (for example 100 % and 150 %); AI Assistant switched on; Task Manager with the GDI objects column
**Time**: 35 minutes

The automated tests cover the tab order, the help logic and the scaling
maths. These checks need a real keyboard, real monitors and Task Manager.

## Settings keyboard path

1. **Tab order**
   Do: Open Edit > Settings... Press Tab repeatedly, then Shift+Tab repeatedly. Do it on a page with a disabled control or a hidden one.
   Expect: Tab moves through the nav list, then each enabled control from top to bottom, then Cancel and Save, then wraps to the nav list. Shift+Tab goes back. Disabled and hidden controls are skipped. A focus ring shows where you are.
   If it fails: Note the page and where the focus went wrong.
   Result:

2. **A long page scrolls to the focus**
   Do: Open the Voice page, then the Debugging page with Enable debugging ticked. Press Tab through the page.
   Expect: The page scrolls so the focused control is always in view.
   If it fails: Note the page and the control that was out of view.
   Result:

3. **F1 help**
   Do: Click a control and press F1. Press Escape. Press F1 again, then Tab. Press F1 again, then drag the window by its title bar. Press F1 again, then scroll the page with the wheel.
   Expect: F1 shows the same help as hovering. Escape hides it without closing Settings. Tab hides it. Dragging the window or wheel-scrolling hides it.
   If it fails: Note which step left the tip showing or closed the dialog.
   Result:

## Scale

4. **Moving Settings between monitors**
   Do: Open Settings. Drag it from the 100 % monitor to the 150 % one and back.
   Expect: Fonts, rows and buttons rescale. Nothing overlaps. The window takes the size Windows suggests.
   If it fails: Screenshot after each move.
   Result:

5. **Minimum width**
   Do: At 100 % and then at 150 %, drag Settings to its smallest width. Open the Debugging page with Enable debugging ticked.
   Expect: No row runs past the right edge.
   If it fails: Screenshot and note the scale.
   Result:

6. **About page**
   Do: Open Settings > About.
   Expect: The version line, the copyright line and the description are all shown, with no stray text at the top left.
   If it fails: Screenshot.
   Result:

## The Session Manager form

7. **Help tips and closing**
   Do: Open File > Session Manager... and add or edit a session. Hover each field for a moment. Click a field and press F1. With a tip showing, click Cancel. Open the form again, show a tip, and click the title-bar X. Open it again, show a tip, and press Escape.
   Expect: Each field has a help tip and F1 shows it. With a tip showing, Cancel and the X close the dialog. Escape closes only the tip.
   If it fails: Note the field or the control that did not behave.
   Result:

8. **The Platform tip**
   Do: Show the help tip for the Platform field.
   Expect: The tip mentions "Auto-detect".
   If it fails: Copy the tip text.
   Result:

## The AI panel and DPI

9. **Moving the panel between monitors**
   Do: Open the AI panel with a conversation. Press Ctrl+= twice in the chat. Move the panel to the other monitor, once docked (move the main window) and once floating. Move it back.
   Expect: Text, gaps, chips and icons all rescale. The zoom step is kept. Tooltips and click targets line up with what you see.
   If it fails: Screenshot and note the two scales.
   Result:

10. **No leaked objects**
    Do: Show the GDI objects column in Task Manager (Details tab, Select columns). Note the count for nutshell.exe. Repeat the move from check 9 about ten times.
    Expect: The count stays flat, give or take a few.
    If it fails: Note the first and last counts.
