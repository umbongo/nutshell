# v1.3.5: shortcuts (PR pending)

**Status**: NOT RUN
**Needs**: an SSH session or the local shell, two tabs open; AI Assistant switched on
**Time**: 20 minutes

The automated tests cover the chord table and the forwarding logic. These
checks use the real keyboard and windows.

## Tabs and zoom in the terminal

1. **Ctrl+Tab cycles the tabs**
   Do: Open two or more tabs and click in the terminal. Press Ctrl+Tab several times, then Ctrl+Shift+Tab several times.
   Expect: Ctrl+Tab goes to the next tab and Ctrl+Shift+Tab to the previous one, both wrapping round at the ends. Nothing is typed in the shell.
   If it fails: Note which key did nothing or typed text.
   Result:

2. **One tab**
   Do: Close all tabs but one. Press Ctrl+Tab.
   Expect: Nothing happens.
   If it fails: Note what changed.
   Result:

3. **The keys do not reach the program**
   Do: In a session run `cat -v`. Press Ctrl+Tab, then Ctrl+0. Press Ctrl+C to end it.
   Expect: Nothing arrives from either key.
   If it fails: Note what `cat -v` printed.
   Result:

4. **Ctrl+0 resets the terminal zoom**
   Do: Click in the terminal. Press Ctrl+= twice, then Ctrl+0. Then press Ctrl+= twice again and press Ctrl+Numpad 0.
   Expect: Both times the terminal font returns to 10 pt.
   If it fails: Note the size you see after each reset.
   Result:

## From the AI panel

5. **Ctrl+0 in the AI input**
   Do: Click in the AI input box. Press Ctrl+= twice, then Ctrl+0.
   Expect: The chat font resets to its default. The terminal font does not change.
   If it fails: Note which font changed.
   Result:

6. **Main-window chords from the input box**
   Do: With focus in the AI input box press Ctrl+Tab. Then Ctrl+Shift+T. Close it. Then F11, and F11 again. Then Ctrl+Shift+Space. Repeat the last one to show the panel again. Do this once with the panel docked and once floating.
   Expect: Ctrl+Tab switches tab and types no tab character. Ctrl+Shift+T opens the Session Manager. F11 toggles fullscreen. Ctrl+Shift+Space hides the panel, docked or floating.
   If it fails: Note the chord, whether the panel was docked, and what happened.
   Result:

7. **From the panel's buttons**
   Do: Click New chat, then press Ctrl+Tab, Ctrl+Shift+T and F11. Then click Send (with an empty box) and repeat.
   Expect: The same chords work with focus on a button.
   If it fails: Note the button and the chord.
   Result:

8. **A floating panel with Settings open**
   Do: Float the AI panel. Open Edit > Settings... Click in the panel's input box. Press Ctrl+Shift+T, then Ctrl+Shift+W.
   Expect: Nothing happens. No Session Manager opens and no tab closes.
   If it fails: Note what opened or closed.
   Result:

9. **Send Next Key Raw**
   Do: In a session run `cat -v`. Choose Edit > Send Key > Send Next Key Raw. Click in the AI input box and press Ctrl+Tab.
   Expect: The tab switches. The remote session receives nothing.
   If it fails: Note what `cat -v` printed.
   Result:

10. **Plain typing still works**
    Do: In the AI input box type a line, press Shift+Enter, type another, then use Ctrl+A, Ctrl+C and Ctrl+V. Press Enter.
    Expect: Typing, Shift+Enter (new line), Ctrl+A, Ctrl+C and Ctrl+V all work as before. Enter sends.
    If it fails: Note which key behaves wrongly.
    Result:
